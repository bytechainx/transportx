# transportx 标准文档

**crate**：`transportx` v0.1.0 | **角色**：驱动无关的 HTTP / WebSocket 传输边界

---

## 1. 需求标准

### 目标

transportx 提供 HTTP/WS 传输能力：HttpDriver（HTTP 驱动）、WsConnector（WS 连接器）、TLS 配置、客户端池、代理配置。

### 边界

- **包含**：HttpDriver（流式响应上限）、WsConnector（解码前帧/消息上限）、TlsConfig/TlsMode、HttpClientPool（配置校验、RAII lease、兼容手动借还）、ProxyConfig
- **不包含**：完整生产 TLS/mTLS 产品、自定义协议
- **依赖**：reqwest、tokio-tungstenite、async-trait、bytes、httpdate、thiserror、tokio
- **零内部耦合**：不依赖任何业务 crate；错误统一为 `TransportError`

---

## 2. 设计标准

### 架构

```text
transportx
├── http        — HttpDriver (reqwest 封装)
├── ws          — WsConnector (tokio-tungstenite)
├── tls         — TlsMode / TlsConfig
├── pool        — HttpClientPool（工厂 + 错误回滚）
└── proxy       — ProxyConfig
```
